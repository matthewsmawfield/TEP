# TEP Analysis and Verification Pipeline Scripts

This directory contains the reproducible computational and symbolic verification pipeline for Paper 0 (*The Temporal Equivalence Principle: Dynamic Time, Two-Metric Geometry, and the Foundations of Emergent Light Speed*).

## Top-Level Utilities

- `generate_site_pdf.py` — Renders the built HTML manuscript (`site/dist/index.html`) into the publication PDF (`A0-TEP-v0.16-Jakarta.pdf`) with embedded XMP/DOI metadata.
- `utils/` — PDF rendering, compression, and post-processing utilities (`html_to_pdf.py`, `process_pdf.py`, `compress_pdf.py`).

## Shared Pipeline Modules (`steps/`)

- `tep_model.py` — Shared radial boundary-value solver, physical constants, and master-potential definitions used across the canonical potential and compact-body steps.
- `legacy_screening.py` — Normalized-field comparison routines (three-potential comparison, three-zone PREM profile, stellar-population scan, and nested hierarchy) called by `step_01_radial_ode.py`.

## Pipeline Steps (`steps/`)

All step scripts write their reproducible JSON artifacts to `../results/` relative to the repository root.
