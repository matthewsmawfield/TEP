This directory contains reproducible outputs from the TEP analysis pipeline. All manuscript numbers, figures, tables, and statistical claims trace to files in this directory.

- `step_01_radial_ode.json` — Radial scalar field BVP solutions for Earth, Sun, neutron star, black hole, and galaxy. Physical-λ solar scan emitting the screened-source PPN check γ_PPN−1 = −4β_A²S_Σ/(1+2β_A²S_Σ), linear in S_Σ because the photon probe is unscreened (Burrage & Sakstein 2018, Eq. 3.31), evaluated with the far-field (1 AU) source charge — the binding Cassini test (reference λ gives γ_PPN−1 ≈ −5.8×10⁻³, failing the 2.3×10⁻⁵ bound by ~250×; the bound S_Σ ≲ 5.75×10⁻⁶ is met for μ_0 ≳ 10^10) — plus near-field conjunction diagnostics at 1.6 R_⊙ and wide-binary-separation diagnostics at 2646 AU (x_max = 10^6 R_⊙) reported separately, plus the legacy normalized-field sections (three-potential comparison, 3-zone density profile, stellar-population scan, nested galaxy→Sun→Earth hierarchy) via `scripts/steps/legacy_screening.py`. Generated by `scripts/steps/step_01_radial_ode.py`.
